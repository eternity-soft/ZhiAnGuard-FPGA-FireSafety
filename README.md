# 智安卫士 FPGA消防科普系统 V27 提交版

## 1. 工程入口

- TD 6.2 工程：`02_FPGA_PROJECT/src/td_project/V27_FIRE_ALL_IN_ONE.al`
- 顶层模块：`anlogic_topic1_hdmi_media_top`
- 目标器件：安路 EG4S20BG256
- 最终位流：`04_PROGRAM_FILES/V27_FIRE_ALL_IN_ONE.bit`
- 位流 SHA256：`B1DC520692EAE24C8AB68F923DFBC8C7E35D7FA43B7E7ED8A351B3C17904FC69`

## 2. 主要功能

- TF 卡 BMP 图片读取、SDRAM 帧缓存和 HDMI 640×480 音视频输出。
- 不同分辨率图片等比例适配；当前缩放器采用横向最近邻取样，放大时进行纵向线性插值，缩小时对上下两个样本取平均。
- 手动切图、1/2/4 秒自动轮播、淡入淡出、亮度与音量四档调节。
- Sobel 边缘检测、异常像素监测及恢复、启动与切图保护。
- 顶部状态栏、运行时间、消防滚动字幕、提示音/背景音乐两路音源电平条。
- 消防知识问答、消防应急演练、火场逃生游戏三类互斥交互模式。

## 3. 按键说明

| 实体按键 | 短按 | 长按 |
|---|---|---|
| KEY1 | 返回第一张图片 | 进入/退出火场逃生游戏 |
| KEY2 | 下一张图片；交互界面确认/前进 | 开关边缘检测 |
| KEY3 | 切换轮播周期；交互界面跳过/灭火 | 进入/退出消防知识问答 |
| KEY4 | 开关自动轮播；交互界面切换/转向 | 进入/退出消防演练 |

拨码 SW1/SW2 控制音量四档，SW3/SW4 控制亮度四档。

## 4. 构建与仿真

1. 在 TD 6.2 中打开 `V27_FIRE_ALL_IN_ONE.al`。
2. 也可在工程根目录执行 `run_td_build.ps1`；如工具安装路径不同，请传入 `-ToolDirectory`。
3. 集成仿真入口为 `03_SIMULATION/run_v27_modelsim.ps1`。

本提交副本已于 2026-10-29 重新运行 V27 集成仿真：编译 0 错误、0 警告，问答、演练、游戏的进入/退出及互斥测试全部通过。

## 5. 实板结果

- V27 位流已烧录，当前功能未发现异常。
- 自动轮播连续运行 6 小时，未发现蓝屏、花屏、卡死或异常切换。
- 资源与时序数据以 `05_BUILD_REPORTS` 内 V27 报告为准。
